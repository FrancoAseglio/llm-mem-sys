# Predictions

Written before the run they describe, committed first, and kept unchanged. One file per set, named `set_<X>.md`. `set_F.md` also holds the write-path predictions (it was called `write_path_and_set_F.md`).

| File | Covers |
|---|---|
| `set_E.md` | set E |
| `set_F.md` | the write path and set F |
| `set_G.md` | set G (episodes) |
| `set_H.md` | set H (blind, with notes) |
| `set_I.md` | set I (past questions) |
| `set_J.md` | set J (consolidation) |
| `set_K.md` | set K (consistency across sessions) |
| `set_L.md` | set L (blind, unseen data, every question type) |
| `set_M.md` | set M (blind, long crowded histories; the main hypothesis) |
| `set_N.md` | set N (blind, long crowded histories; hybrid against the baseline) |
| `set_O.md` | set O (blind, the final test; hybrid against the baseline, pooled with N) |

The result files they mention are listed with their new names in [../results/README.md](../results/README.md).
